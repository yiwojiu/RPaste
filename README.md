# R-Paste

一个 Windows 剪贴板历史工具。`Alt+V` 唤出，打字即搜，回车粘贴。

目标是"按下到贴上"这条路足够短：窗口常驻托盘，唤出时立刻可用，搜索在内存里跑，
不需要等数据库。文本、图片、文件路径都能记。

## 特性

- **毫秒级搜索**：常驻内存的索引，1 万条记录全量扫描约 2 ms，通常的查询在微秒级。
- **拼音首字母**：`wj` 能搜到「文件」。只压汉字首字母，纯代码/路径不受影响。
- **命中高亮 + 上下文**：搜索时显示命中词附近的内容，不用猜为什么这条被选中。
- **全文浮层**：长文本按 `Alt+Enter` 打开完整正文，自动滚到命中处。
- **图片与文件**：图片存缩略图 + 原图，剪贴板里的文件列表也能记。
- **收藏置顶**：`Ctrl+P` 置顶，清空历史时收藏项保留。
- **类型筛选**：`Ctrl+0/1/2/3` 在全部 / 文本 / 图片 / 文件之间切换。
- **序号直达**：`Alt+1`~`Alt+9` 直接粘贴第 N 条，不用先上下选。
- **来源标记**：每条记录标出复制时所在的程序（Chrome、终端、Excel…），粘之前能确认没拿错。
- **去尾空行粘贴**：`Ctrl+Enter` 粘贴前裁掉尾部空行——从终端复制的命令粘回去不会直接执行。
- **热键可改**：`Alt+V` 只是默认值。设置里点「修改」按下新组合即可，立即生效；组合被占用会当场提示。
- **窗口尺寸记忆**：拖到合适大小后关掉，下次打开按这个尺寸恢复；换到更小的屏幕时会自动收缩到工作区内。
- **保存上限可调**：默认留最近 1 万条，可在设置里改成 1 千 / 3 千 / 3 万；改小当场按最旧优先淘汰，收藏项不受影响。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Alt+V` | 唤出 / 收起窗口（全局，可改） |
| `↑` `↓` | 在列表中选择 |
| `Enter` | 粘贴选中项 |
| `Ctrl+Enter` | 粘贴并裁掉尾部空行 |
| `Alt+1`~`Alt+9` | 直接粘贴第 N 条 |
| `Ctrl+P` | 收藏 / 取消收藏 |
| `Delete` | 删除选中项 |
| `Ctrl+0/1/2/3` | 全部 / 文本 / 图片 / 文件 |
| `空格` | 搜索框为空时：图片看大图、文本看全文 |
| `Alt+Enter` | 任何时候打开全文 / 大图浮层 |
| `Ctrl+K` | 打开 / 关闭设置面板（也可点筛选行右侧「设置」、或右键托盘图标选「设置…」） |
| `Esc` | 关闭浮层 / 设置；都没有时收起窗口 |

搜索框支持空格分词（多词是「与」关系），大小写不敏感。

## 安装

从 [Releases](https://github.com/yiwojiu/RPaste/releases) 下载 `rpaste.exe`，放到任意目录双击运行即可。
无安装程序。设置（热键、窗口尺寸、保存上限、开机自启）写在 `HKCU\Software\RPaste`，删掉即恢复默认。

要求 64 位 Windows 10 及以上。

## 构建

需要 Rust 1.85+（`edition = "2024"`）。

```bash
cargo build --release
```

产物在 `target/release/rpaste.exe`。SQLite 是 `bundled` 编译进去的，运行时没有额外依赖。

`examples/` 下是开发用的验证工具（真实按键输入、窗口截图、基准测试），不参与主程序构建，
用 `cargo run --release --example <名字>` 单独跑。其中 `bench_search` 是搜索性能基准，
`search` 可以直接在命令行查本地库。

## 数据

全部数据在 `%LOCALAPPDATA%\RPaste\`：

| 文件 | 内容 |
| --- | --- |
| `rpaste.db` | SQLite 元数据（预览、长度、时间、收藏位） |
| `blobs\` | 超过 64 KB 的内容，按哈希存原文件 |
| `rpaste.log` | 运行日志，出问题先看这个 |

- 单条内容上限 64 MB，历史最多保留 10000 条（超出淘汰最旧的非收藏项）。
- 预览存前 512 字，另有最多 16K 字尾部正文参与搜索——8 KB 的脚本不会只有开头能搜到。
- 去重按 `blake3(内容)`，同一内容重复复制只更新时间，不会产生两条。

## 一些取舍

- **不用 SQLite FTS5**：trigram 分词器有 3 字门槛、`ORDER BY rank` 比全表扫描慢两个数量级，
  而且多词会被拼成短语。改成进程内索引后，查询时间从 13 ms 降到微秒级，库体积也从
  10.4 MB 降到 7.0 MB。代价是预览常驻内存（1 万条远小于 20 MB）。
- **拼音首字母自己生成**：GB2312 一级汉字按拼音排序，据此离线生成一张 3755 字的
  首字母表，零依赖，不用引入拼音库。
- **粘贴走写回剪贴板 + 模拟 `Ctrl+V`**：不碰目标窗口的输入法状态，兼容性最好。
- **单实例**：第二个进程会把已有窗口叫出来，避免同一次复制记两遍。

## 已知限制

- 仅支持 Windows（大量 Win32 调用：剪贴板监听、全局热键、托盘、窗口激活）。
- 图片暂时只存 PNG，`Ctrl+V` 粘贴原图，不转换格式。
- 拼音首字母只覆盖前 512 字，长文本的尾部正文不走拼音路径。
