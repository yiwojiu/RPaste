R-Paste 内嵌字体许可说明
=========================

字体      : Noto Sans SC（思源黑体）
来源      : C:\Windows\Fonts\NotoSansSC-VF.ttf（随 Windows 发行）
版本      : 2.04
字重      : 原字体为可变字体，wght 100–900；本项目固定为 Regular (400)
版权      : Copyright 2014-2021 Adobe (http://www.adobe.com/),
           with Reserved Font Name 'Source'
许可证    : SIL Open Font License, Version 1.1
官方全文  : https://scripts.sil.org/OFL

本项目 assets/font.ttf 属于「修改版」(Modified Version)：
  - 用 fontTools.varLib.instancer 实例化到 wght=400，去掉可变轴
  - 用 fontTools.subset 裁剪到 GB2312 全集 + ASCII + 常用标点，共 7,707 字
  - 去掉 hinting 与 DSIG 表
复现方式见 tools/subset_font.py。

OFL 条件 2 要求随软件分发的每一份拷贝包含版权声明与本许可证。
分发 rpaste.exe 时请一并附上本文件。
Reserved Font Name 为 'Source'，本修改版沿用 'Noto Sans SC' 名称，不违反条件 3。
